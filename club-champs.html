Grades 7 to 14

Children’s club championships 2026/27

Our club championships run inside the Saturday children’s interclub at Ngā Puna Wai. Every North Canterbury athlete who competes in a championship event earns points towards their grade’s overall club champion.

See the standings Programme How points work

Points so far

Standings

Points add up across the season, separately for each grade. Grade is the athlete’s age on 31 December. The overall club champions are celebrated at prize-giving at the end of the season.

    Which events count

    Programme

    Each championship event is run as part of that Saturday’s interclub, so enter it as usual. If an interclub is cancelled, its championship events move to a date in 2027.

    Event by event

    Results

    Placings count North Canterbury athletes only, within each grade, so an athlete’s place here is not their place in the whole race. Event champions are recognised at Tuesday training.

      How points work

      Points come from interclub results, counting North Canterbury athletes only, in your grade. You are guaranteed points for competing in a championship event.
